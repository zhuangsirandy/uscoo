# Security policy

## Supported version

Security fixes are currently applied to the latest `0.1.x` release line on `main`.

## Report a vulnerability

Do not open a public issue for a security or privacy vulnerability. Email `coo@uscoo.ai` with the subject `[SECURITY] USCOO` and include:

- the affected route or component;
- reproduction steps using synthetic data;
- the likely impact; and
- a suggested mitigation, if known.

Do **not** attach real case records, credentials, database exports, access tokens, or applicant documents. The maintainers will acknowledge a usable report and coordinate disclosure after a fix is available.

## Deployment responsibility

Operators are responsible for access control, data retention, encryption, backups, processor agreements, incident response, and compliance in their own deployment. Rotate a secret immediately if it is ever committed or exposed.
